# Challenge Amigo-Secreto

<p>
En este desafío, desarrollarás una aplicación que permita a los usuarios ingresar nombres de amigos en una lista para luego realizar un sorteo aleatorio y determinar quién es el <strong>"amigo secreto"</strong>.
</p>

## Usabilidad

<p>
El usuario podrá ingresar nombres mediante un campo de texto. Al hacer clic en el botón <strong>"Adicionar"</strong>, el nombre se añadirá a una lista visible en la página. Los nombres ingresados se mostrarán en una lista que el usuario puede ver y revisar.<br></brPara>Para finalizar, el usuario podrá hacer clic en el botón <strong>"Sortear Amigo".</strong> El sistema seleccionará uno de los nombres de la lista de forma aleatoria y mostrará el resultado en la pantalla.
</p>

### Funcionalidades:

<ol>
  <li><strong>Agregar Nombres:</strong> Los usuarios escribirán el nombre de un amigo en un campo de texto y lo agregarán a una lista visible al hacer clic en <strong>"Adicionar"</strong>.</li>
  <li><strong>Validar Entrada:</strong> Si el campo de texto está vacío, el programa mostrará una alerta pidiendo un nombre válido.</li>
  <li><strong>Visualizar la Lista:</strong> Los nombres ingresados aparecerán en una lista debajo del campo de entrada.</li>
  <li><strong>Sorteo Aleatorio:</strong> Al hacer clic en el botón <strong>"Sortear Amigo",</strong> se seleccionará aleatoriamente un nombre de la lista y se mostrará en la página.</li>
</ol>
